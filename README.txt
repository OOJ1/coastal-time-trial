============================================================
  COASTAL TIME TRIAL · 黄昏海岸计时赛
  微信分享 / 离线单机版（全程序化 3D 渲染，零外部素材）
============================================================

【这是什么】
一款基于 Three.js（r149，本地内置）的 3D 黄昏海岸环形计时赛小游戏。
画面（地形、海面、天空、车辆、特效）全部由代码程序化生成，
音效由 Web Audio 实时合成——不需要任何图片/音频素材文件，
也没有任何外部网络依赖，纯本地即可运行。

【怎么玩 / 怎么打开】
  • 电脑：直接双击本文件夹里的  index.html  ，用任意现代浏览器打开即可。
  • 手机：用文件管理器把压缩包解压，进入 coastal-time-trial 文件夹，
         点击  index.html  ，选择浏览器打开即可游玩。
  （推荐用 Chrome / Edge / Safari。全屏加载动画完成后即可出发；首次按任意键或点一下屏幕解锁音效。）

【操作说明】
  桌面键盘：
    W / ↑      油门
    S / ↓      刹车 · 倒车
    A / D      左转 / 右转
    SPACE      手刹漂移
    SHIFT      氮气加速
    C          切换视角（追车 → 远景 → 第一人称，循环）
    V          切换驾驶权（两辆车各自独立，互不覆盖）
    F          第一人称视角调节面板（开 / 关）
    R          原地复位
    ENTER      重新开始一局
    M          音效开关
  手机触屏（自动显示虚拟按键，横屏体验最佳）：
    左下：左右转向   右下：油门 / 刹车 / 氮气 / 漂移
    右上：视角 / 复位 / 重开 / 音效 / 换车 / 调视角（触屏无换档键）
  手柄（Xbox / 标准映射，插上即用，无需安装驱动外的任何东西）：
    RT 右扳机  油门（模拟量：轻踩小油门，踩到底是全油门）
    LT 左扳机  刹车 · 倒车（同样是模拟量）
    左摇杆左右 转向（带死区 + 指数曲线，回中更稳）
    十字键     ↑↓ 油门刹车、←→ 转向（摇杆不习惯时的数字兜底）
    A / RB     手刹漂移
    B / LB     氮气加速
    Y          切换视角（追车 → 远景 → 第一人称，循环）
    X / START  原地复位
    A          升档（仅 MP4/4，手柄独占；原厂车仍是手刹漂移）
    X          降档（仅 MP4/4，手柄独占；原厂车仍是原地复位）
    RB         手刹漂移（驾驶 MP4/4 时的手刹键）
    START      原地复位（驾驶 MP4/4 时的复位键）
    L3 按下     切换驾驶权（左摇杆垂直按下去）
    R3 按下     第一人称视角调节面板（右摇杆垂直按下去）
    BACK       音效开关
    说明：插上手柄后左上会弹「手柄已连接」，左下键位提示自动多一行手柄说明；
          撞击与氮气点火有轻微震动，不想要可设 CR.Pad.settings.rumble = false。
          声音仍需一次鼠标点击或键盘按键解锁（浏览器不允许手柄输入解锁音频），
          想听引擎声按一下 M。

【两辆车（V 键切换驾驶权）】
  两辆车是各自独立的实体，但**同一时刻只有一辆在赛道上**：
    · 原厂跑车  —— 程序化生成的默认车（发车线）
    · MP4/4 · 你的车 —— 由 mp44.blend（你自己在 Blender 里建的模型）导入
    · 没在开的那辆停在**终点线附近、画面左侧（环内草地侧）护栏/空气墙之外的展示位**（约在赛道
      中心线左侧 9.5m，左侧硬限制 5.8m），**明确不放在右侧海侧**；场景里看得见，但玩家被护栏挡着，
      开不到也撞不到它，所以不需要车车碰撞。
  按 V（手柄 L3 / 触屏「换车」）切换「当前开哪一辆」：
    · **被切走的车移到展示位；被切到的车新开一局**：强制放回自己的发车原点
      （两车 HOME 错开 30m），速度 / 氮气 / 撞击状态全部归零，
      圈速计时从 0:00.000 重新开始，本机排行榜切到这辆车。
    · 两辆车的历史成绩都保留；切回来时按上一条规则重新从原点起步。
    · R 复位 / ENTER 重开只作用于当前驾驶的车；HUD 计时与检查点按车分槽。
    · 两辆车各有**一份独立的本机 TOP 5**（HUD 标题带车型名），不同调校的车
      不混排；旧版本 cr.lb.v1 里没有车型标签的历史成绩统一归入原厂跑车。
  物理调校按车型独立（见下），相机 / 音效 / 特效自动跟随当前驾驶的车。

【原厂跑车操控（本轮提升）】
  横向抓地 grip 9.5 → 12.5、抓地上限 maxLat 18 → 23（约 +30%），
  草地侧向上限 11 → 14、抓地恢复 2.2 → 2.6、横摆响应 10 → 11.5、
  转向角上限 1.0 → 1.06、漂移门槛 3.6 → 4.2、车身侧倾 0.0042 → 0.0036。
  过弯更稳、方向盘更跟手，但仍明显弱于 MP4/4（27.5 / 49）；
  手刹档 gripHand / maxLatHand 保持两车一致，拉手刹照样能漂移。
  引擎 / 档位 / 草地纵向阻力（0.18）不变。

【MP4/4 抓地力（大幅增强）】
  横向抓地 grip 9.5 → 16.2、抓地上限 maxLat 18 → 30.6（约 +70%），
  漂移触发门槛 3.6 → 6.5，横摆响应更快，车身侧倾更小：
  过弯几乎不甩尾，适合专心刷圈速。
  **手刹档两车参数保持一致**，所以拉手刹仍然能漂移、仍然能触发漂移充能。
  本轮平衡（略微回调操控）：grip 30→27.5、maxLat 54→49、草地侧向上限 30→25，
  漂移门槛 12→10.5、横摆响应 9.5→9.0、转向角上限 0.84→0.80；仍是原厂车
  （9.5 / 18）的约 2.8 倍，过弯依旧稳，但不再「贴地轨道」般没有反馈。
  参数集中在 src/car.js 的 Car.TUNES[1]，想再调直接改数值即可；
  Car.TUNES[0] 的操控保持原值（只调了草地阻力）。

【加载动画与分阶段场景加载】
  打开 index.html 先进入全屏加载动画：落日、海平线、波纹、进度条、阶段文案与百分比，
  全部纯 CSS + 原生 JS，零外部素材。11 个阶段按帧推进，每阶段渲染一帧当前场景，
  背景遮罩随进度变薄，所以能看到地形 → 雪山/海面 → 公路 → 灯塔植被 → 两辆车 →
  后处理链逐层长出来；着色器编译与首帧预热也放在这段时间，进游戏后不会临时卡顿。
  阶段：赛道与天空 / 海岸地形 / 雪山与海面 / 公路护栏 / 灯塔植被 / 两辆赛车 /
        胎痕尾焰彩条 / HDR 后处理 / 仪表输入音效 / 编译着色器 / 预热首帧。
  完成后显示「准备就绪」并淡出，才启动主循环。控制台可查 CR.Loader.diag()。

【帧率优化与自适应画质】
  · 阴影改为按需更新：太阳静止，阴影贴图最多每 1/30 秒重绘一次
    （低帧率时仍每帧更新），省掉静止光照下多余的阴影 pass。
  · 软件渲染 / 触屏自动把 MSAA 从 4× 降到 2×，场景 RT 填充率减半。
  · 画质按真实 fps 分 5 档自动升降（CR.CFG.autoTier=false 可锁定满配）：
    氮气色差 → 远景 DOF → Bloom 5 级降 3 级 → 半分辨率 AO → 渲染分辨率 0.7；
    每级 6 秒冷却，物理、输入与 HUD 完全不受影响。
  · renderer.info 改为整帧统计一次，便于核对 draw call 与后处理 pass 数。
  · 默认仍是满配：后处理全开、Bloom 5 级、分辨率 1.0、桌面阴影 4096²。

【第二辆车视觉锚点（本轮修复）】
  MP4/4 的车尾、轮距、轮胎位置都和原厂车不同，之前尾焰 / 胎痕 / 尾尘 / 刹车灯
  全用原厂车写死的局部坐标，喷在车底或车尾之外。现在 Car.ANCHORS[2] 每车一份：
    · 尾焰：车尾中央两侧（x±0.30、y0.52、z-2.20），不再贴着后轮/地面；
    · 胎痕：后轮接地点（x±0.846、z-1.656），与真实后轮对齐；
    · 尾尘：车尾后 2.05m（原厂 1.7m），不再从车底冒烟；
    · 刹车灯：移到尾翼下方车尾段内，刹车时亮度 0.9→6；非驾驶车强制熄灭。
    · 前轮拆成左右两个独立轮组，能跟方向盘转动；手刹只锁后轮，不再连前轴一起锁死。

【草地阻力 / 两车平衡】
  草地纵向阻力不再两车共用 CR.CFG.offroadDrag(0.30)，改为按车型分槽：
    · 原厂跑车 0.30 → 0.18（草地上更顺、更不容易被拖停）；
    · MP4/4   0.30 → 0.50（下压力大、轮胎宽，冲出赛道掉速更明显）。
  这样「原厂车容错高、MP4/4 赛道内快但越野惩罚重」的差异更清楚。

【第一人称视角调节（F 键）】
  先按 C 切到「第一人称」，再按 F（手柄 R3 / 触屏「调视角」）打开面板，
  9 个滑块实时预览、自动存到 localStorage，刷新后设置仍在：
    眼高 / 左右位置（正=左舵）/ 前后位置 / 视线俯仰 /
    基础视野 FOV / 速度视野 / 氮气视野 / 过弯侧倾 / 视线距离
  面板上有「恢复默认」；调节只影响第一人称，追车 / 远景两档不受影响。
  参数对象为 CR.Cam.fp，也可以在浏览器控制台里直接改。

  模型已烘成静态网格数据（car2data.js），不需要 GLTFLoader，也不需要联网；
  每辆车有自己的 root / 车身组 / 轮组，轮子滚动沿用原车 Car.sync 逻辑。
  切换时屏幕上方会短暂显示当前车型名。


【MP4/4 变速箱（手柄独占）】
  6 速手动档，只有手柄能换档：A 升档、X 降档；键盘和触屏没有换档键。
  没接手柄时自动按车速升降档（HUD 显示「自动」），接上手柄自动切「手动」，
  手柄断开会回到自动档并复位到 3 档，不会卡在 1 档。
  每档有扭矩倍率与该档极速阈值：低档起步猛但很快断油，必须升档才跑得快；
  高档极速高但起步肉。换档有 0.12s 扭矩中断和一下短震。
  换档还有合成音效：升档是短促上扬的「咔哒」+ 齿轮咬合，降档多一段补油「轰」
  （转速匹配 blip）；只在手动档触发，自动档静音，避免频繁跳档吵。
  音效默认静音，需按 M 或先点一下画面解锁音频。
  HUD 速度表上方显示当前档位，接近断油提示「↑ 升档」、低速高档提示「↓ 降档」。
  档位只对 MP4/4 生效，原厂车完全没有档位概念。
  同时引擎增强：基础推力 13.5→19.5、极速阈值 68→98、风阻 0.0021→0.0018。

【第一人称：车身不再被裁掉】
  原相机近平面 near=1 会把 1 米内的车身整片裁掉，只剩一个被切开的白色截面。
  现在第一人称专用 near=0.25（追车/远景仍用 1，不影响后处理 AO 深度精度），
  鼻锥、座舱、前翼都能完整看到。F 面板新增「近平面裁剪」滑块，
  想少看/多看近处车身可自己调（0.01~1.0，越小看到越多；太小会看到座舱内壁）。

【引擎制动（松油门倒拖）· 已加强】
  松开油门、没踩刹车、没点氮气且车在前进时，发动机变成阻力：
  倒拖强度随车速（转速）上升，40m/s 以上继续增强（原先 46m/s 就饱和），
  并按档位放大 —— 1 档约 1.44 倍、6 档约 0.89 倍，
  所以降档本身就是一种减速手段，出弯前降档能明显帮忙收速。
  MP4/4 的倒拖系数 5.2→9.6，另加高速增益 0.60；原厂车仍是 2.0（手感基本不变）。
  实测 30m/s 松油门滑行 1 秒：原厂 26.6，MP4/4 1档 20.0 / 3档 21.1 / 6档 22.8
  （加强前 1 档是 24.0，即多掉约 4m/s）。
  物理上做了上限保护：任何子步都不会把正速度拖成倒退。
  音频层也跟着变：松油门时排气变闷、进气收掉，音色随倒拖强度渐变。
  参数在 src/car.js 的 Car.TUNES[*].engineBrake / engineBrakeHi，想调直接改数值。

【换档音效音量】
  升档「咔哒 + 上扫」、降档「咔哒 + 下扫 + 补油 blip」三段增益整体放大 2.3 倍，
  仍走原有压缩器（threshold -18 / ratio 5），不会削爆。
  想再大/再小：控制台执行 CR.Audio.shiftVolume = 3.0（1.0 = 初版音量），
  或改 src/audio.js 里的 A.shiftVolume，立即生效、不用刷新。
  记得按 M 或点一下画面解锁音频；静音时换档音会安静跳过。

【游戏规则】
  环形赛道计时赛：**每完成一圈都记一条成绩**（不再只记本局第一次），
  榜单只保留最快的 5 条；最近一圈用暖橙高亮，没进前 5 时单独补一行显示。
  HUD 显示当前圈的已用时间（不是倒计时），LAST 显示刚跑完的那一圈。
  每辆车各有一份本机 TOP 5（存在浏览器 localStorage，标题带车型名）。
  重新开始一局有两条路径，都只作用于当前车：
    · ENTER      → 回到本车的发车原点、计时清零；
    · V / 换车   → 切到目标车并把目标车放回它自己的发车原点、计时清零、
                  切到该车的 TOP 5；被切走的车移到终点左侧护栏外的展示位。
  两条路径共用 Garage.home[i] 这份坐标（车0 发车线 / 车1 后退 30m 偏左 2.2m），
  不会把两辆车叠到同一格。R 仍是「就近拉回中心线」的原地复位，不改计时。
  重开只清计时与高亮，**不会清空也不会锁住榜单**，每一圈照常记录。

【离线说明（重要）】
  • 本游戏为单机离线版，不依赖网络。
  • 代码里原本有一个“向博客后端上报成绩”的接口（/api/game/score），
    离线时该上报会自动失败并静默跳过，完全不影响游戏与本地排行榜。
  • 浏览器对 file:// 下的 localStorage 有限制（部分浏览器隐私模式会降级），
    此时排行榜仅当次会话有效，属正常现象。
