============================================================
  COASTAL TIME TRIAL · 黄昏海岸计时赛
  微信分享 / 离线单机版（全程序化 3D 渲染，零外部素材）
============================================================

【这是什么】
一款基于 Three.js（r149，本地内置）的 3D 黄昏海岸环形计时赛小游戏。
画面（地形、海面、天空、车辆、特效）全部由代码程序化生成，
音效由 Web Audio 实时合成——不需要任何图片/音频素材文件，
也没有任何外部网络依赖，纯本地即可运行。

【怎么玩 / 怎么打开】
  • 电脑：直接双击本文件夹里的  index.html  ，用任意现代浏览器打开即可。
  • 手机：用文件管理器把压缩包解压，进入 coastal-time-trial 文件夹，
         点击  index.html  ，选择浏览器打开即可游玩。
  （推荐用 Chrome / Edge / Safari。首次按任意键或点一下屏幕即出发。）

【操作说明】
  桌面键盘：
    W / ↑      油门
    S / ↓      刹车 · 倒车
    A / D      左转 / 右转
    SPACE      手刹漂移
    SHIFT      氮气加速
    C          切换视角
    R          原地复位
    ENTER      重新开始一局
    M          音效开关
  手机触屏（自动显示虚拟按键，横屏体验最佳）：
    左下：左右转向   右下：油门 / 刹车 / 氮气 / 漂移
    右上：视角 / 复位 / 重开 / 音效

【游戏规则】
  环形赛道计时赛：冲过终点线即记一次本局圈速，倒计时 HUD 显示当前用时。
  HUD 右下角有本机 TOP 5 排行榜（纯本地，存在浏览器 localStorage）。

【离线说明（重要）】
  • 本游戏为单机离线版，不依赖网络。
  • 代码里原本有一个“向博客后端上报成绩”的接口（/api/game/score），
    离线时该上报会自动失败并静默跳过，完全不影响游戏与本地排行榜。
  • 浏览器对 file:// 下的 localStorage 有限制（部分浏览器隐私模式会降级），
    此时排行榜仅当次会话有效，属正常现象。

【文件夹结构】
  coastal-time-trial/
  ├─ index.html        ← 主入口（全屏独立版，双击它）

      ├─ post.js  record.js  hud.js  audio.js
      ├─ camera.js  input.js  touch.js  main.js
